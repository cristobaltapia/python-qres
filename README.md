# Cubus reader for python #

This package provides a python API to read `*.qres` files generated by the Cubus software.

## Installation

Install via Poetry with

```bash
poetry install
poetry build
pip install dist/cubus_reader-1.1.0.tar.gz
```

## Quick start ##

You can read the data from a `*.qres`-file as a pandas DataFrame as:

```python
import numpy as np
import matplotlib.pyplot as plt

from cubus_reader import read_cubus_file, read_cubus_file_as_dataframe

# Read the *.qres file
data = read_cubus_file_as_dataframe('./Data_Test.qres')

# Plot the data
data.plot()
plt.show()
```
